# Greenhouses

Late-game structures where the player sets temperature, humidity, and light directly.

**The guardrail:** if full climate control lets you grow anything anywhere, it deletes the environment system the whole game is built on. So greenhouses are **expensive to run** — heat costs fuel, humidity costs water, light costs power. They're a precision instrument for hard problems, not a blanket.

The target feeling: *"I'm burning a week of profit to hold this one bed at cave conditions because I'm three generations from cracking the glow problem."*

## Implementation status

_Not started. Deferred until the late game. Depends on expression-from-environment ([genetics](04-genetics.md)) and the running-cost economy ([utilities](10-utilities-and-self-sufficiency.md)). No failure state: run dry and the greenhouse drifts to ambient._
