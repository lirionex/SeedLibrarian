# Core loop

There isn't one, and that's deliberate. What there is instead:

- Several beds running at once, at **staggered generation lengths** (2–8 days), so the player is never waiting on a single thing — only choosing which of six things in flight to attend to.
- A pool of available requests larger than the player can accept, so choosing is the gameplay.
- Standing orders that never complete, so there is always something worth doing without accepting anything.
- Wild expeditions when the gene pool lacks what a goal needs.
- Processing, documentation, and bed preparation filling the gaps between sowings.

Waiting is structural. Because growth takes real days, parallelism isn't optional — it's the shape of the game.
