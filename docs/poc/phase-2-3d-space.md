# Phase 2 — Only if Phase 1 passes (2–3 weeks)

The second question, and only worth asking once the first is answered yes:

> **Does 3D space add anything, or is this secretly a menu game?**

Greybox valley: capsule for the player, coloured cubes for plants, three altitude zones. No art, no shader, no house. Walk out, collect, walk back, sow.

**You're checking:** does physically going to the ridge feel meaningfully better than a button that says "go to the ridge"? Does walking between beds add texture or friction?

This is a real question with a real chance of a "no", and the answer determines the entire scope of the project. Be genuinely willing to hear that this is a beautiful 2D game.

## Gate

> 3D adds something a button doesn't.
