# Seed Library

A cozy 3D botany game about breeding plants, keeping a library, and slowly going self-sufficient. You run a small seed library at the foot of a valley, cross plants across generations to fill requests, and build up a notebook that becomes your toolkit and your tech tree at once.

Solo or 2–4 player co-op. Procedural flora. Soft music.

> Status: **pre-production.** No code yet — the current work is design and proof-of-concept planning. The core question to answer first is whether the breeding loop is fun with no art and no 3D. See the POC plan.
